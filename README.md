# L-GRU: Long-term Time Series Forecasting via Lightweight Gated Recurrent Units with Segmented Memory Propagation

This repository contains the official code for the paper **L-GRU: Long-term Time Series Forecasting via Lightweight Gated Recurrent Units with Segmented Memory Propagation**.

## Running

After downloading this project, double-click the `run.bat` file to run it.

> Note: Please ensure that the experimental environment is properly configured before running.
